# Create Big Cannons: Autocannon Revolution

机械动力火炮：机炮弹药革命 — 为 [Create Big Cannons](https://github.com/Cannoneers-of-Create/CreateBigCannons) 添加多种新型机炮弹药。

## 弹头 / Projectiles

- **APFSDS Projectile** — 动能穿甲弹，穿深40
- **APHE Projectile** — 穿甲高爆弹，穿深14
- **SAP Projectile** — 半穿甲弹，穿深12
- **Shrapnel Projectile** — 榴霰弹，40枚破片密集散布
- **Thermite Projectile** — 铝热剂弹头，撞击点方块挖掘+引燃
- **Multi-Purpose Grenade** — 多用途榴弹，小型破甲/爆炸
- **Frag Grenade** — 低速破片榴弹，8枚子母弹碰撞引爆，全向抛射
- **Smoke/Potion Round** — 烟雾/药水弹，可装载滞留药水

## 弹药 / Cartridges

- **High-Velocity Cartridge** — 2倍初速机炮弹药，支持大部分弹头

## 工具 / Tools

- **Soul Fire Device** — 与弹药合成，附加火焰爆炸 + 25%最大生命伤害

## 已删除 / Removed

- ~~Smart Fuze~~ — 智能引信（v1.09已删除）
- ~~Fuze Controller~~ — 引信控制器（v1.09已删除）

## 特性 / Features

### 低速破片榴弹 (v2.1)
- 不具备反装甲能力，速度极低
- 爆裂后释放8枚子母弹，全向随机散布
- 子母弹碰撞引爆或5tick定时引爆
- 每枚子母弹二次爆炸释放大量破片
- 不可用于高速机炮弹药

### 烟雾/药水弹 (v2.1)
- 不具备穿甲能力
- 不可装备灵魂火装置
- 无药水模式：撞击产生烟雾云团（小规模）
- 药水模式：与滞留药水合成后，撞击产生药水云团（小规模）
- Shift可查看当前装载的药水效果

### 高速机炮弹药
- 初速为普通弹药2倍
- 支持弹头：APFSDS/APHE/SAP/Shrapnel/Thermite/MultiPurpose/Smoke

### 灵魂火装置
- 可附加到APHE/SAP/Shrapnel/Thermite/MultiPurpose弹药
- 爆炸时产生火焰 + 对3×3×3格内生物造成25%最大生命伤害
