# Create Big Cannons: Autocannon Revolution

为 [Create Big Cannons](https://github.com/rbasamoyai/CreateBigCannons) 扩展的机炮弹药模组。

> 🎵 **[▶ 打开带音乐的介绍页面](https://qkdream.github.io/Create-Big-Cannon-Autogun-Revolution/index.html)**（自动循环播放 + 停止按钮）

## 新增弹药

| 弹药 | 类型 | 穿深 | 爆炸 | 特色 |
|------|------|------|------|------|
| **APFSDS** | 动能穿甲 | 300 | 无 | 极高穿深，低阻力，几乎不跳弹 |
| **APHE** | 穿甲高爆 | 14 | 6.0 | 穿透后内部爆炸 |
| **SAP** | 半穿甲 | 10 | 8.4 | 高装药量，爆炸伤害高 |
| **榴霰弹** | 霰弹 | 0 | 5.0 | 40枚破片，密集散布，单发破片伤害8.0 |
| **铝热剂弹头** | 燃烧穿甲 | 0 | 4.0 | 撞击点挖掘 + 引燃，可装灵魂火装置 |
| **灵魂火装置** | 附魔装置 | — | 2.0 | 为弹药附加火焰爆炸 + 15%最大生命伤害 |

## 高速机炮弹药

- 初速为普通弹药的 **2倍**
- 合成：filled_autocannon_cartridge + 2×火药 → 空高速弹壳
- 装填：任意弹头 + 空高速弹壳 → 高速弹药
- 升级：任意已装填弹壳 + 火药 → 高速弹药
- 支持装引信 + 灵魂火装置
