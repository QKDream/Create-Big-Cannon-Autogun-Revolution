# Create Big Cannons: Autocannon Revolution

机械动力火炮：机炮弹药革新 - 为 [Create Big Cannons](https://github.com/Cannoneers-of-Create/CreateBigCannons) 添加多种新型机炮弹药。

| 物品 | 类型 | 描述 |
|------|------|------|
| APFSDS Projectile | 弹头 | 动能穿甲弹，穿深14 |
| APHE Projectile | 弹头 | 穿甲高爆弹，穿深14 |
| SAP Projectile | 弹头 | 半穿甲弹，穿深8 |
| Shrapnel Projectile | 弹头 | 榴霰弹，40枚破片 |

| Multi-Purpose Grenade | 弹头 | 多用途榴弹，小型破甲/爆炸 |
| Soul Fire Device | 工具 | 与弹药合成附加火焰爆炸+15%HP伤害 |
| High-Velocity Cartridge | 弹药 | 2倍初速机炮弹药 |
| **Smart Fuze** | **引信** | **智能引信，支持碰炸/定时/近炸三种模式** |
| **Fuze Controller** | **方块** | **引信控制器，GUI远程控制智能引信** |

## Features / 特性

### 智能引信系统 (v1.07)
- 智能引信可绑定到引信控制器方块
- 引信控制器GUI可视化切换碰炸/定时/近炸模式
- 近炸模式可调触发距离（0.5-32格）
- 兼容SABLE结构检测
- 无需从弹药箱取出即可切换引信模式

### 高速机炮弹药
- 初速为普通弹药2倍
- 支持所有弹头类型（APFSDS/APHE/SAP/Shrapnel/Thermite/MultiPurpose）

### 灵魂火装置
- 可附加到任何机炮弹药上
- 爆炸时产生火焰 + 对1格内生物造成15%最大生命伤害
